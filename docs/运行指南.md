# 运行指南

[返回文档索引](README.md) · [项目首页](../README.md) · [噪声层定义](运动模糊噪声层.md)

本文依据当前 `main.py`、`data_loader.py` 和 `solver.py` 整理。所有命令从仓库根目录执行。

## 1. 环境与运行入口

代码使用 Python 3.10+。必需依赖为 `torch`、`numpy`、`scipy`、`opencv-python`、`Pillow`、`kornia`；训练曲线和进度显示分别使用 `matplotlib`、`tqdm`。

```bash
python -m pip install torch
python -m pip install numpy scipy opencv-python Pillow kornia matplotlib tqdm
python -c "import torch; print(torch.__version__); print('CUDA:', torch.cuda.is_available())"
python main.py --help
```

使用 GPU 时需安装与设备兼容的 PyTorch 构建。当前没有依赖版本锁定文件，上述安装命令也不代表已经验证过所有软件版本组合。

入口是 `main.py`。无参数启动默认从头训练 `ScreenShootingMB`，不显示功能选择菜单。`cli/` 与 `ui/` 中仍有辅助功能，但是否接入入口应以 `main.py` 为准。

## 2. 数据准备

### 2.1 训练与仿真验证：COCOMask

`train_mask` 与 `eval_mask` 使用同一类拼接图：

```text
单张样本：128×256（高×宽）
┌────────────────┬────────────────┐
│ 宿主图 128×128 │ mask 128×128   │
└────────────────┴────────────────┘

Datasets/
└── COCOMask/
    ├── train/train_class/  # 训练图像文件
    └── val/val_class/      # 验证图像文件
```

加载器以 `image_size` 为左右分界，直接取左侧宿主和右侧 mask，**不会自动缩放训练拼接图**。默认使用 `--image_size 128`；改变尺寸前需检查网络中解码器的固定展平维度等结构约束。

图像由 OpenCV 读取，当前内部通道顺序为 BGR，宿主张量为 `[3, H, W]`，数值归一化到 `[-1, 1]`。mask 按代码变换为感知损失权重。

每张样本生成 30-bit 消息：训练时随机采样；评估时按排序后的样本索引固定消息。此处固定的是消息，噪声层仍随机采样。

### 2.2 嵌入与外部拍屏测准：独立图像

`test_embedding` 和 `test_accuracy` 读取普通图像，并缩放到 `image_size×image_size`。文件名应包含可解析的非负数字索引，例如 `0.png`、`12.jpg`、`test12.png`；统一使用纯数字文件名更便于匹配输出和参考图。

这两种模式都需要 `.mat` 水印矩阵：

- 参数为 `--wmat_dir`，虽然名称含 `dir`，实际应传入文件路径。
- 文件中键名必须为 `w`，形状应为 `N×30`，消息为 0/1 比特。
- 文件索引 `i` 读取 `w[i, :]`，索引从 0 开始，必须小于矩阵行数。
- 嵌入与测准须使用同一份消息矩阵，不能在测准前重新随机生成。

当前默认路径为 `results/WatermarkMatrix/w.mat`。图像、水印矩阵和外部拍屏后的矫正图都需自行准备。

### 2.3 两个输入目录

`main.py` 无论执行哪种模式，都会先创建两个 DataLoader：`--image_dir` 和 `--image_val_dir`。因此两个目录都须存在，并符合当前 `--dataset` 对应的数据格式。

- 训练：两者分别指向训练集和验证集。
- 仿真验证：可将两者设为同一验证目录，实际遍历 `image_val_dir`。
- 嵌入：可将两者设为同一宿主目录，实际遍历 `image_dir`。
- 拍屏测准：可将两者设为同一矫正图目录，实际遍历 `image_val_dir`。

## 3. 训练

```bash
python main.py --dataset train_mask --mode train_mask --distortion ScreenShootingMB --image_dir Datasets/COCOMask/train/train_class/ --image_val_dir Datasets/COCOMask/val/val_class/
```

默认设置：`batch_size=16`、`num_epoch=100`、`num_workers=1`、`image_size=128`、判别器 `num_channels=64`；消息、图像和对抗损失权重 `lambda1/lambda2/lambda3` 分别为 `3/1/0.001`。`Solver` 的默认学习率为 `1e-3`。

`--embedding_epoch 0` 为从头训练。非零时，训练分支从 `models/<distortion>/<model_name>_mask_<embedding_epoch>.pth` 加载网络权重，并从该 epoch 开始计数；它不恢复优化器状态。`--num_epoch` 是循环终点，而非在已有 epoch 上追加的轮数。

`--weight_path` 用于评估、嵌入和测准，训练分支不会用它初始化。`Solver` 内部仍保留 `init_from_ckpt`、`lr`、`warmup_epochs`、`save_policy` 等配置，但当前命令行未暴露这些参数。

训练会记录日志、保存权重，并调用 epoch 曲线显示函数。有图形后端时可能弹出窗口；目前入口未提供关闭曲线窗口的参数。

## 4. 仿真验证

DMB 权重与 DMB 噪声层：

```bash
python main.py --dataset eval_mask --mode eval_mask --distortion ScreenShootingMB --weight_path models/Encoder_Decoder_Model_mask_ScreenShootingMB_best.pth --image_dir Datasets/COCOMask/val/val_class/ --image_val_dir Datasets/COCOMask/val/val_class/
```

ScreenShooting 基线：

```bash
python main.py --dataset eval_mask --mode eval_mask --distortion ScreenShooting --weight_path models/Encoder_Decoder_Model_mask_ScreenShooting_best.pth --image_dir Datasets/COCOMask/val/val_class/ --image_val_dir Datasets/COCOMask/val/val_class/
```

`--distortion` 选择本次前向使用的噪声层，加载权重不会自动切换噪声层。两条命令分别评估各自模型与各自噪声配置；比较模型鲁棒性时，应另外在同一退化条件下交叉评估并记录配置。

始终同时使用 `--dataset eval_mask --mode eval_mask`。仅设置 `--mode eval_mask` 而保留默认训练 dataset，会走训练模型的构建路径，不能作为标准的已加载权重验证流程。

## 5. 嵌入水印

准备 `Datasets/images/` 中的独立宿主图与水印矩阵后执行：

```bash
python main.py --dataset test_embedding --mode test_embedding --distortion ScreenShootingMB --weight_path models/Encoder_Decoder_Model_mask_ScreenShootingMB_best.pth --image_dir Datasets/images/ --image_val_dir Datasets/images/ --wmat_dir results/WatermarkMatrix/w.mat
```

当前 `test_embedding()` 输出五联可视化拼图，顺序为：宿主图、含水印图、噪声图、梯度 mask、放大残差。默认每块宽 128 像素。

产物位于 `results/Image_test_ScreenShootingMB/images_embed_0/`，文件名为 `<索引>.png`。这里的 `0` 来自默认 `embedding_epoch`，不表示权重文件对应第 0 轮。当前函数不单独导出纯含水印图；实际拍屏前需要自行提取拼图中的含水印区域，或另行实现独立导出流程。

## 6. 外部拍屏图像测准

准备已矫正的拍屏图 `Datasets/Recover/`，保留与原宿主一致的数字索引，使用嵌入时的同一份 `w.mat`：

```bash
python main.py --dataset test_accuracy --mode test_accuracy --distortion ScreenShootingMB --weight_path models/Encoder_Decoder_Model_mask_ScreenShootingMB_best.pth --image_dir Datasets/Recover/ --image_val_dir Datasets/Recover/ --wmat_dir results/WatermarkMatrix/w.mat
```

该模式将输入直接送入 Decoder，**不会再次施加仿真噪声**。`--distortion` 在此不表示又给拍屏图增加一次退化。

PSNR 参考图从 `Datasets/images_watermarked/` 按 `<索引>.<扩展名>` 查找，应为与拍屏图对应的纯含水印图。缺失参考图时仍可报告 Acc/BER；PSNR 只统计成功匹配的样本。当前入口未暴露内部的 `psnr_ref_dir` 参数。

采集、矫正和裁图脚本已不在当前仓库中，需在外部完成后再使用本模式。

## 7. 输出与指标

默认输出路径：

- 训练日志：`logs/runs/<run_id>.json`、同名 `.txt`。
- 每次训练的权重：`models/runs/<run_id>/`；`models/LATEST_RUN.txt` 指向最近一次训练目录。
- 最佳权重：DMB 为 `models/Encoder_Decoder_Model_mask_ScreenShootingMB_best.pth`；基线使用对应的 `ScreenShooting_best.pth`。
- 训练可视化：`results/Image/images/`；同名产物可能由后续运行更新。
- 仿真验证图：`results/Image_eval_<distortion>/<权重标识>/`。
- 仿真验证摘要：`logs/eval_mask_<distortion>_<权重标识>.txt`。
- 嵌入拼图：`results/Image_test_<distortion>/images_embed_<embedding_epoch>/`。
- 拍屏测准看板及摘要：`results/Image_accuracy/`；当前仅在有 PSNR 参考样本且启用可视化时写入。

全局最佳权重和部分可视化路径会更新；需要保留一次实验的完整产物时，可用 `--log_dir`、`--model_save_dir`、`--result_dir` 指定独立输出目录，并显式指定评估权重。

解码输出以 `>=0.5` 判为 1。`BER` 是错误比特数除以总比特数，`Acc (%) = 100×(1−BER)`。

两种 PSNR 的参考不同：

- `eval_mask`：含水印图对原宿主图，衡量嵌入失真。当前实现先按每个 batch 的整体 MSE 算 PSNR，再对 batch 等权平均。
- `test_accuracy`：矫正后的拍屏图对对应含水印图，衡量拍屏与矫正后的图像差异。当前实现按有效参考样本逐图算 PSNR 后平均。

两者不能直接混作同一指标。训练/验证中的 PSNR 也不是噪声图对宿主图的 PSNR。

## 8. 参数边界与复现记录

当前命令行支持：

- 模式：`--dataset`、`--mode`。
- 网络与训练：`--image_size`、`--num_channels`、`--batch_size`、`--lambda1`、`--lambda2`、`--lambda3`、`--num_epoch`、`--embedding_epoch`、`--distortion`。
- 输入与权重：`--weight_path`、`--image_dir`、`--image_val_dir`、`--wmat_dir`。
- 输出与加载：`--log_dir`、`--model_save_dir`、`--model_name`、`--result_dir`、`--num_workers`、`--log_step`、`--model_save_step`。
- `--test_iters` 仍在解析器中保留，当前权重选择应使用 `--weight_path`。

旧文档中的 `--eval_ckpt`、`--eval_path`、`--lite`、`--full`、`--no_interactive`、`--embed_strength`、`--no_epoch_plot` 均不属于当前入口参数。DMB 的位移、旋转、曝光采样等参数目前通过 Python 构造函数设置，见[噪声层文档](运动模糊噪声层.md)。
