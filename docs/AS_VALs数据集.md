# AS_VALs 数据集（历史资料）

[返回文档索引](README.md) · [当前数据准备说明](运行指南.md)

## 1. 当前状态

AS_VALs 原用于观察屏摄噪声与运动模糊对合成文本的影响。旧文档将其展开为 **ASCII VALs Dataset**，其中 VALs 指变量字符串。

当前仓库已移除 `AS_VALs/`、文本图像生成脚本、图像产物和 `manifest.txt`。本文保留历史规格，不能作为随仓库可直接运行的数据生成流程。当前 DMB 噪声层实现在 `Noise_Layer.py`，不依赖该数据集。

主训练与仿真验证使用 COCOMask 拼接图，格式见[运行指南](运行指南.md)。

## 2. 历史记录的规格

以下内容来自既有项目文档，尚未以原始脚本和数据重新核验：

- 数量：15,000 张。
- 图像：600×600、RGB、PNG，白底黑字。
- 文件名：`00000.png` 至 `14999.png`。
- 内容：可打印 ASCII，包含字母、数字、标点及少量空格。
- 排版：最多 2 行，每行最多 6 个字符；旧文档描述总长上限为 12。
- 内容比例：约 40% 英文短词/短语、60% 随机 ASCII 字符串。
- 字体：随系统可用字体变化，旧记录提及 Arial Bold 等 TrueType 字体。
- 清单：`manifest.txt`，每行以制表符分隔文件名与字符串。

清单格式示意（不代表当前可下载的真实样本）：

```text
00000.png<TAB>example
00001.png<TAB>A1!b
```

`<TAB>` 表示一个实际制表符。字符串若含空格或标点，应以原始清单为准。

## 3. 待核验的几何布局

旧文档同时写有“画布 600×600”“四周页边距 100”和“可写区域 500×500”，三者不一致：

- 若每侧页边距为 100，可写区域应为 `600−2×100=400`，即 400×400。
- 若可写区域为 500×500，则每侧页边距应为 50。

目前缺少原生成脚本和图像，无法确认实际采用哪一种布局。论文、报告或重建数据集时应先找回原始材料，不能将旧版 500×500 与 100 像素边距同时作为已确认规格。

## 4. 历史用途与复现条件

历史用途包括文本拖影可视化、摩尔纹/透视观感检查和裁窗运动模糊实验。它与训练所需的 `[宿主图 | mask]` 拼接图格式不同，字符串清单也不能代替 30-bit 水印消息矩阵。

旧路径 `AS_VALs/outputs/text_images/` 仅是历史产物位置，当前不存在。若恢复该数据集，需一并补回并核验：

1. 生成脚本、随机种子、字体与版本信息。
2. 画布、真实页边距、排版和自动字号规则。
3. 图像与原始清单，以及图文对应关系。
4. 数据划分、内容比例和可复现的样本数量。

完成核验前，本文仅作历史说明，不提供基于缺失路径的加载命令或可直接用于论文的确定性数据集描述。
