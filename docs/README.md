1. [运行指南](运行指南.md)：环境依赖、数据格式、训练、评估、嵌入、拍屏测准、输出路径及指标口径。
2. [运动模糊噪声层](运动模糊噪声层.md)：位姿模型、曝光积分、边界策略、摩尔纹耦合、默认参数和代码接口。

## 历史资料

- [AS_VALs 数据集](AS_VALs数据集.md)：已移除文本测试集的历史规格；生成脚本、图像和清单均不随当前仓库提供，其中几何布局存在待核验项。

## 文档维护约定

- 命令行示例以 [`main.py`](../main.py) 中的 `argparse` 定义为准。
- 噪声层行为以 [`Noise_Layer.py`](../Noise_Layer.py) 的实际调用路径为准；辅助函数具备的能力不等于训练入口已经启用。
- 评估与输出以 [`solver.py`](../solver.py) 为准；区分仿真验证与外部拍屏图像测准。
- 新增实验结论时记录数据、权重、参数和指标口径；历史设计或未验证数值应明确标注。
- 目录与接口调整后同步更新链接，运行参数集中维护在运行指南中。
